This is a curated copy of the meeting packet kept in git (guide, deck, final figures, CSVs, reviews, provenance, failure evidence).
The complete packet (extra generator outputs, superseded first-draft figures, slide crops, the self-contained HTML guide) is in
`$CS282A_DATA/results/meeting_packet_v1/` on the machine that produced it. The scripts that generated it are in `scripts/packet/`.
Start with GUIDE_READ_FIRST.md and README_PACKET.md (paths in README_PACKET.md refer to the full packet).
`simulator_evidence/contact_reproduction_5e0ae3f_v2/` is the reproduction of the original contact failure (an earlier run with a flawed
summary column was left out of this copy). Everything is idealized 1D Coulomb dynamics, one seed, no observation noise.
