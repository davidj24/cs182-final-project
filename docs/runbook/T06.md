# T06 runbook: evaluation harness

Nothing here is needed to run before a model exists. Commands for later (T07), all fast
(references over ~100-item test sets: seconds; model predictions: seconds on CPU/GPU).

Source commit: record `git rev-parse HEAD` of the integration branch at launch.
Working directory: repo root, after `. workflow/env.sh`.
Dataset version: the `$CS282A_DATA/datasets/vN` used by training (contains meta.json, e1-e4.npz).
Seed: `--seed` only seeds the paired bootstrap (default 0).

References only (no model):
    python scripts/eval_run.py --dataset-dir $CS282A_DATA/datasets/v1

With the trained model (T05 provides `module:function` returning `(model, norm)` from the
checkpoint; config hash and checkpoint SHA must be verified by T07 per PILOT_SPEC O7):
    python scripts/eval_run.py --dataset-dir $CS282A_DATA/datasets/v1 --model-loader <module>:<fn>

Outputs: new `$CS282A_DATA/results/vN/` with e1_*.csv/png, e2_*, e3_*, e4_*, and `ref_cache/`
(reference predictions keyed by predictor + item fingerprint; never overwritten). Reuse an
earlier run's references (e.g. across seeds) with `--reuse-cache $CS282A_DATA/results/vK`.
How to check: every CSV starts with `# ` header lines giving the standardized-MSE denominator and
`bayes: unavailable` or the Bayes D; `pytest tests/eval` passes; E3 figure carries the
"Preliminary no-noise redundancy test..." label.
