# Runbook T05: pilot training run (launch with run_job.sh)

- Source commit: SHA of exp/train as integrated into soomi-integration (fill at launch; `git rev-parse HEAD`).
- Working directory: the integrated worktree root (contains scripts/, src/).
- Environment: `. /home/exx/soomi/soomi_projects/cs282a_project/workflow/env.sh` (never uv sync).
- Dataset: `$CS282A_DATA/datasets/<VERSION>` (placeholder: the T04 pilot dataset, e.g. v1; must be real, not synthetic; train.py refuses synthetic).
- Config hash: written to runs/<run_id>/config.json (`cmd_config_sha256`) together with dataset file sha256s and source git SHA.
- Seed 0, noise 0.

## Benchmark (done on synthetic rows, one RTX 4090, GPU 1, shared machine)
`CUDA_VISIBLE_DEVICES=1 python scripts/bench_train.py --steps 300` -> 75.3 steps/s, 424k tokens/s,
peak 1.21 GiB, 0.22 min per 1000 steps, 9,485,057 parameters.
Chosen budget: 120,000 steps = ~27 min of pure training at that speed (+ validation); with a
slower/shared GPU the --max-seconds guard (2700 s = 45 min) stops it, but that truncates the
cosine schedule, so re-run bench on the launch GPU first if it is busy. Warmup = 2000 (5% = 6000, capped).
Note: 1,000 training cubes will be seen many times; best-val checkpoint guards overfitting.

## Command (expected 27-45 min, 1 GPU)
```
cd <worktree> && . /home/exx/soomi/soomi_projects/cs282a_project/workflow/env.sh
CUDA_VISIBLE_DEVICES=<free gpu> python scripts/train.py \
  --dataset $CS282A_DATA/datasets/<VERSION> --steps 120000 --seed 0 --noise 0 \
  --eval-every 1000 --max-seconds 2700 --run-id pilot_<VERSION>_n0_s0
```
Outputs: `$CS282A_DATA/runs/<run_id>/{config.json, meta.json (train-only normalization), metrics.jsonl, best.pt, last.pt}`.
(A new id with suffix _1 is used if the run id already exists; nothing is overwritten.)

## How to check it worked
- stdout prints `parameters: 9,485,057` and the run dir.
- last line of metrics.jsonl has `"type": "final"`, no `stopped_early` record (else the schedule was truncated), finite losses.
- `grep '"type": "val"' metrics.jsonl | tail`: val loss fell from ~1 (standardized MSE) and best.pt step is recorded in the checkpoint (`torch.load(...)['step']`).
- config.json `source_git.dirty` is false and `dataset_files_sha256` match the dataset meta.json.
