# T03 Phase B plan: MuJoCo-mode Bayes (pilot, optional)

Frozen inputs (DECISIONS): f = clipped analytic_displacement; r_model = 9.5e-7; tau_abs = 1e-4 m;
sigma_d = 0 (noise 0); training prior m log-uniform [0.5, 1.5], mu U[0.3, 0.6]; broad prior
(PROTOCOL §8) m log-uniform [0.35, 2.0], mu U[0.2, 0.7]. Target space: raw standardized is affine
in d, so the posterior mean is computed in metres and equals the standardized posterior mean
after the same affine map. Bayes valid for the declared ideal dynamics only (A4).

Likelihood (PROTOCOL §8): dedupe by measurement_id; group by identical action (F, k), canonical
sort; group mean ybar (members sorted by id); per group log N(ybar; f, sigma_d^2/n + tau^2),
tau = r_model f + tau_abs, including -0.5 log(2 pi var). Prior uniform in (u = log m, mu).

Numerical scheme (the hazard: posterior relative width ~1e-5..1e-4, far below a 400-grid cell;
single-force contexts give a thin ridge spanning the box). Nested adaptive quadrature, N = 400:
- Inner (mu at fixed u): f is affine in w = 1/mu (f = c1(m,a) w - c0(m,a) when moving), so the
  conditional likelihood is (to ~1e-5) Gaussian in w with weighted-least-squares centre/width.
  Window = points of [1/mu_hi, 1/mu_lo] within exp(-K^2/2), K = 12, of the interval max; uniform
  N-point midpoint grid in mu on that window (constant cell weight, exact prior, window edges
  coincide with prior edges when clipped). Exact likelihood evaluated on it; self-check: log-weight
  at interior window ends <= max - 30, else widen and redo. c = 0: whole interval.
- Outer (u): N midpoint cells on [log m_lo, log m_hi]; log Z(u) = log inner integral. Multi-
  resolution zoom: any cell with non-negligible mass (within 50 nats of the max, or neighbour of
  one) whose log Z differs from a neighbour by > delta nats is split into s sub-cells; repeat
  until none flagged. This zooms onto blobs (>= 2 forces) and onto sharp ridge exits (1 force).
- Posterior mean = sum h_i Z_i M_i / sum h_i Z_i with M_i the inner conditional mean of f_query;
  all in log-sum-exp. Diagnostics: levels, cells, unresolved flag (=> status "blocked").
API: bayes_predict(context, query, prior="train"|"broad") -> Prediction ok; posterior_mean(...)
with diagnostics; predict_prefixes(context, query, cs) (incremental group statistics, LRU cache
keyed on canonical groups + query + prior + N). No analytic_exact (out of scope).

Validation (tests/reference/test_bayes.py, brute force in tests/reference/_bayes_brute.py,
written independently: dense 2-D midpoint grids, no WLS windows, no adaptive splitting):
- fast: copies bitwise invariant; c=0 equals closed-form prior mean E[F^2T^2/(2 m^2 mu g) -
  F T^2/(2m)] (train prior, no clipping since F >= 13 N); broad prior c=0 vs dense grid; sigma_d=0
  posterior finite on inconsistent/OOD data; noise-free exact consistency (state error);
  extreme likelihoods finite; prefixes incremental == recomputed bitwise; 400 vs 800 on 2 items;
  harness probe returns ok.
- slow (run once, output pasted in handoff): >= 20 hard cases (light/slippery, heavy/grippy,
  prior-edge truths, close forces, same-force c=2, c = 1, 2, 10, heavy-OOD under train and broad
  priors, 1e-6 relative perturbations mimicking discrepancy). Compare N=400 vs N=800 and vs brute
  force: (u, mu) local dense grid with automatic box expansion around an independently located
  mode for distinct-force cases; (u, v = f(theta, a0)) dense grid over the full u range for
  single-force ridges. Tolerance: relative 1e-3 (report real max). If not met: stay "blocked".
- timing script check: per-call cost so ~1,500 pilot calls run in minutes on CPU.
Deliverables: reference/priors.py, reference/bayes.py, tests, docs/handoffs/T03.md update.
