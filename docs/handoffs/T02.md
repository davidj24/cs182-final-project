## 3. Deviations from PROTOCOL/INTERFACES
- Stratification is a Latin hypercube on (m, mu, F, k); F/(mu m g) is derived, so its bins are reported not stratified exactly (range 1.5-16 in training).
- No near-threshold stratum (training domain never has F/(mu m g) < 1.4); T01 tests cover below-threshold.
- Test-item push count (250 x 11) is an assumption for the projection only.

## 4. Open questions
None. Control decides R1/R2 adoption, ranges, target space.

## 5. Known weaknesses
- Agreement is by construction (A4); the README says so and keeps physical-validity and analytic-validity judgments separate. It does not validate contact physics.
- Errors are tiny (O(dt) Euler), so r_model/tau_abs candidates mostly reflect discretisation and the 1e-4 floor, not real model error.
- Rotation checks are vacuous; frames/replay come from T01's sim_view.py (not rerun here).
