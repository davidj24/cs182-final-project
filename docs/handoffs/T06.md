## 2. How to verify
`. workflow/env.sh && pytest tests/eval -q` (pytest header prints "bayes unavailable -> test_bayes_harness.py not collected").
Hand fixture arithmetic is in the docstring of `tests/eval/test_metrics_hand.py`.

## 3. Deviations / assumptions
- Standardized-MSE denominator read from `meta.json` `normalization.d_obs.std` squared (also accepts `d_obs_std`,
  `d_std`); INTERFACES does not name the key exactly, T04 must match. Raises if absent.
- Tertile edges: 1/3, 2/3 quantiles of the experiment's unique item targets (E4: in-distribution edges, both sets); ties go lower.
- Median relative error excludes zero targets (non-moving pushes), counted in `n_zero_target_excluded_from_rel`.
- "oracle" predictor returns the clean target (error exactly 0, harness sanity); wrap T03's real oracle with FunctionPredictor if it re-simulates.
- References are deduplicated by measurement_id in all experiments; the model sees the full sequence.
- Bayes-as-model: see repair section M2 (stub always runs; real Bayes variant skips visibly).
- Plots use standardized MSE (symlog below 1e-3); physical-unit MSE is in the CSVs. Figure CSV = plotted series; metrics CSVs are `eN_metrics.csv`.

## 3b. Repair cycle 1 (review 4adda4b)
- M1: `run_e2` no longer asserts prefix nesting. New `cases.assert_e2_cells`: per-cell force constraints (A all F_q;
  B all >=3 N away; C contains F_q, distinct; D distinct, none within 3 N) and cross-cell pairing (same cube/query/
  d_query_clean per item_id; A-vs-C and B-vs-D share c, D/C c-sets subset of partner). Raises AssertionError. Tests in `test_repair.py`.
- M2: `pytest_ignore_collect` removed. `test_bayes_harness.py`: stub Bayes as reference and as kind="model" through RefCache,
  identical metric rows, gap == 0, D not None, unconditional. Real-Bayes variant calls `pytest.skip("bayes blocked: <reason>")`
  (reason from new `bayes_status()`); the old test compared a predictor to itself, hence the replacement (not a loosening).
- M3: when D is None, Bayes is dropped from predictors in every runner, CSV and figure (note in header with n_ok count).
  Tests: partially-not_determined stub in E1 and E2/E3/E4. Partial coverage on plotted points is annotated n_ok/n (m5).
- M4: cache file name and payload carry `code_hash` (reference/*.py, physics.py, eval/predictors.py, docs/DECISIONS.md);
  mismatch = miss. CSV headers list the results dirs supplying hits + code_hash. m8: hits are copied into the new
  results/vN/ref_cache; `--out-dir` that exists is refused. `test_cache_reads_earlier_version` assertion changed from
  "v2 has no cache files" to "v2 has the copied file, v1 untouched" (required by m8, not a loosening of a check).
- m1: `dedupe_by_measurement_id` raises ValueError for non-exact repeated ids; `run_e3` calls `assert_e3_copies`.

  (`normalization.d_obs.std`; the unused alternate keys were removed). m6: done with M1. m7: CLI verifies e*.npz sha256 against any
  meta.json `*sha256*` dict (raises on mismatch; header says NOT VERIFIED if meta has no per-file hashes; exact meta key
  name is unconfirmed until T02 output exists), header records dataset version, source SHA key, model-loader spec.

## 4. Open questions

## 5. Known weaknesses
- All tests use synthetic analytic-target items; the npz loader was only checked against a synthetic file written
  from INTERFACES, not real T04 output. `ModelPredictor` untested against real `model_predict` (NotImplemented now).
- Physics-fit availability probed once via a dummy call in `cli.py`; if it is wrong-signature this fails loudly.
- Seeds/SE across training seeds not implemented (pilot has one seed); SE shown is over items.
